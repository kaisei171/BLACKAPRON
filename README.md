# Starbucks Black Apron Exam Prep Web App

スターバックスのブラックエプロン（BA）試験対策用の一問一答Webアプリケーションです。
FY26およびFY27の電車版・試験対策資料に基づき、頻出知識や最新の変更点（ディカフェの製法変更等）を網羅しています。

## 特徴
1. **完全オフライン & サーバーレス**
   - HTML, CSS, JavaScriptのみで構成されており、ブラウザと`localStorage`のみで完結。
2. **たまたま正解・不正解の自動復習システム**
   - 正解時でも「たまたま/不安」ボタンを押すことで要復習リストに保持可能。
   - 不正解時は自動的に要復習リストに追加。
   - 「要復習リスト」タブで苦手な問題だけを集中的に反復演習可能。
3. **GitHub Pagesに完全対応**
   - リポジトリにPushしてPagesを有効化するだけで、スマホやPCからすぐ利用可能。

## 公開手順
1. 本ZIPを解凍し、リポジトリに `index.html` と `questions.js` をコミット・プッシュします。
2. リポジトリの **Settings > Pages** で Branch を `main` に設定し保存します。
3. 数分で発行されるURLにアクセスしてください。
